# Div_like Primop Cmm Tests

This directory contains Cmm-level tests for the div_like primop boundary assertions. These tests verify that the runtime assertions work when div_like primops are called directly from Cmm code, not just through Haskell primitives.

## Test Files

### DivLikeGood.cmm / DivLikeGood.hs
Tests good cases that should work normally:
- Basic division operations using `%quot` and `%rem` in Cmm
- Tests Int8, Word8, and Int16 operations
- Calls Cmm functions via `foreign import prim`
- Expected to pass with normal execution

### DivLikeDivByZero.cmm / DivLikeDivByZero.hs  
Tests division by zero that should fail:
- Uses `%quot(42::bits8, 0::bits8)` in Cmm
- Should trigger RaiseDivZeroOp assertion
- Expected to exit with code 1 (failure)

### DivLikeOverflow.cmm / DivLikeOverflow.hs
Tests integer overflow that should fail:
- Uses `%quot((-128)::bits8, (-1)::bits8)` in Cmm  
- Should trigger overflow assertion for signed division
- Expected to exit with code 1 (failure)

### DivLikeComprehensiveCmm.cmm / DivLikeComprehensiveCmm.hs
Comprehensive test covering multiple scenarios:
- Tests both good and bad cases for Int8, Word8, Int16, Int32
- Uses exception handling to catch and verify assertion failures
- Provides complete coverage of Cmm-level div_like operations
- Expected to pass by properly handling both cases

## Cmm Syntax

The tests use Cmm's native division operators:
- `%quot(x, y)` - Quotient operation (equivalent to `/` in most languages)
- `%rem(x, y)` - Remainder operation (equivalent to `%` in most languages) 
- Type annotations: `42::bits8`, `1000::bits16`, etc.
- Sign extension: `%zx64(result)` to convert to 64-bit for return

## Foreign Import Pattern

The Haskell drivers use `foreign import prim` to call Cmm functions:
```haskell
foreign import prim "testQuotInt8" testQuotInt8 :: Int8# -> Int8# -> Word#
```

This pattern allows direct testing of Cmm-level primop calls without going through the Haskell primitive wrapper layer.

## Test Coverage

These Cmm tests verify that the div_like assertions work at the lowest level:

1. **Direct Cmm calls**: Tests the actual machine operations generated by the compiler
2. **Multiple integer sizes**: Int8, Word8, Int16, Int32 operations  
3. **Both signed and unsigned**: Covers overflow for signed, division by zero for all
4. **Integration with RTS**: Verifies that RaiseDivZeroOp is properly called from Cmm

## Configuration

The tests are configured in `all.T` with:
- `req_cmm`: Requires Cmm support to run
- `exit_code(1)`: For tests expected to fail with assertions
- `multi_compile_and_run`: Compiles both Cmm and Haskell files together

This complements the Haskell-level tests in `testsuite/tests/primops/should_run/` by testing the same assertions at the Cmm compilation level.
